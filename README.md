# 乡音桥 · Dialect Bridge

循着一声乡音，探索汉语方言的地理分布与双向听辨实验。

**[打开网页](https://envhyf.github.io/dialect-bridge/)** · [研究依据](docs/research.md) · [地图数据说明](docs/data-method.md)

## 能做什么

- 点击地图或选择家乡，比较两地；有实测则展示双向成绩，没有实测则保留未知。
- 将原图提取的方言轮廓叠在淡行政边界上，不以省界代替方言边界。
- 切换方言分类图层与客家话居民点图层，下载 GeoJSON。
- 查看研究出处与扫描图目录；可在浏览器本地打开自己持有的扫描图，文件不会上传。

## 部署

这是纯静态网页，**无需安装 npm 依赖、无需 API Key、无需打包框架**。

### GitHub Pages

仓库设置 **Settings → Pages → Source: GitHub Actions**。推送到 `main` 后，工作流先运行检查，再自动发布 `dist/`。

Fork 到其他账户后同样适用，资源使用相对路径。部署地址由 GitHub Pages 提供；README 的演示链接可按需修改。

### 其他静态主机

将 `dist/` 中的全部文件上传为网站根目录即可。Netlify / Cloudflare Pages 等平台的输出目录填 `dist`，构建命令可填 `npm run build`（只验证文件，不重新生成地图）。

### 本地预览

安装 Node.js 22 或更高版本后执行：

```sh
npm start
```

访问 `http://127.0.0.1:8768`。检查命令：

```sh
npm test
npm run build
```

## 数据范围

- A2 图像提取的 10 类汉语方言色区；40 个地理控制点，留一验证 RMS 约 21.94 km，仅适合探索性展示。
- 84 个地方变体代表点，不代表全市所有居民。
- 四川盆地 66 个客家话居民点符号，属于局部转录，非全国名录。
- Tang（2009）15 个方言点的 225 个有方向组合，分别有两种实验任务，共 450 条观测。

**实验正确率不等于日常对话理解率。** 只有被实验覆盖的地点配对显示百分数，不外推到整个方言区或片。只考虑汉语方言，不评估少数民族语言。

## 原图与公开版

**此公开仓库及其 Git 历史不包含完整扫描原图。** `dist/atlas/manifest.json` 仅保留图号、标题与尺寸；网页选择的本地图片只在浏览器内读取。

若要复现数字化，可自行将相应扫描图置于被 Git 忽略的 `reference/`，安装 `requirements.txt` 后运行 `python scripts/digitize.py`。脚本只输出衍生地理数据和来源目录，不复制原图到公开目录。发布检查会阻止原图进入部署产物。
