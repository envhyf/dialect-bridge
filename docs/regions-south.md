# 南方片区：来源、配准与边界局限

这份数据是从用户提供的《中国语言地图集》扫描图 B6、B12、B13 逐图人工辨读、按图上像素沿色块/片界概化描摹的 **30 个局部区域**，不是全国完整片区数据库。未复制或发布扫描图。沿用本次提供版本的分类名称，不将其假定为后续版本分类。

- B12：邵将区、闽北区、福宁片、侯官片、闽中区、莆仙区、大田片、泉漳片、潮汕片。
- B13：高阳片、四邑片、吴化片、雷州片、客家粤北片东部主体、粤中片及粤台片的嘉应、兴华、新惠小片。
- B6：昆贵片云南—贵州主体、滇西片姚理/保潞小片及姚理滇中块、黔北片、黔南片、岑江片、湘南片、成渝片主体、武天片、桂柳片及灌赤片西充岛。

`partialCoverage=true`、`coverageComplete=false` 对所有区域成立。沿海群岛、零散语言岛、较小内部孔洞、重叠兼用语言区域未全部逐一描摹；昆贵片不包含所有北部孤立分布，粤北片仅取东部主体。因此 UI 应显示「局部覆盖 / 人工概化」，不能显示为片区完整的精确测绘边界。B12 台湾、海南均为独立插图，本次完全排除，没有套用大陆配准参数。B13 的韶州土话和少数民族语言块没有当作客家片区整体录入。

## 坐标与复现

运行 `python scripts/regions_south.py`。工作预览宽度 1800 像素，原扫描尺寸分别为 B12 3100×2299、B13 3116×2307、B6 3060×2298。源像素按宽度比转换为 native coordinates，保存在每项 `sourceBoundary`；`sourceImageSize` 可供 SVG 叠图核验。

每图单独用城镇符号中心配准，控制点经纬度采用约略的城镇中心 WGS84 坐标，二阶像素—经纬度回归。控制点数量 B12 21、B13 16、B6 16。配准参数、控制点和逐图误差存于 metadata。没有使用行政边界、城市缓冲圆或 Voronoi 构造方言区。

|图幅|拟合 RMSE|留一控制点验证 RMSE|最大留一误差|
|---|---:|---:|---:|
|B12|2.21 km|3.45 km|6.76 km|
|B13|5.51 km|8.57 km|16.00 km|
|B6|4.19 km|9.33 km|25.27 km|

`registrationRMSEKm` 在 GeoJSON 中专指留一验证值；训练拟合值另存 `registrationTrainingRMSEKm`。B6 最差留一误差出现在最北端西安控制点，属于外推；并不意味着南方每段边界都偏离 25 km。但这些指标只评价配准，**不包含人工简化、旧地图制图、城镇中心位置或漏绘语言岛等误差**。边界需要更多控制点、逐段细描和独立核查后，才能用于县乡级判断。

本地 QA 叠线图在被 gitignore 排除的 `qa/south-B6-overlay.jpg`、`qa/south-B12-overlay.jpg`、`qa/south-B13-overlay.jpg`，不随网站发布。叠图后修正了 B6 泸州、贵阳、大理、保山等控制点对文字/符号中心的误读；修正了 B12 泉漳西缘及北部片区的初稿轮廓。所有 30 个输出几何通过 Shapely validity 检查；昆明 WGS84 点落于昆贵片区域内。

## 互通研究

几何、分类相同不能证明互通率相同。本文件没有任何片区对的实验互通率；全部 `mutualIntelligibilityEvidence=no-region-pair-measurement`。若另有某城市话的研究，界面只能作为该地点的研究证据列出，不得传播成整个片或小片的百分比。

新增成渝片、武天片、桂柳片后，成都和重庆落在成渝片、汉口落在武天片、桂林落在桂柳片。桂柳北缘复用黔南/岑江/湘南原有节点，西缘复用昆贵节点。成渝片内部西充岛以同一组像素分别作为成渝内洞和灌赤片岛，避免凭行政边界填充；小片归属不清楚，所以只标到灌赤片。

复核 B12 发现初稿闽北—侯官、闽北—福宁共享边界偏离原线。已用 3 倍及 5 倍局部原图重新逐段描边，并令相邻区域复用同一源像素折线；没有用任意裁切消除重叠。修正后这两组重叠为 0，全部同图幅配对的面积重叠低于较小区域的 1%（最高约 0.98%）；原图配准误差与跨图幅的不一致仍保留。


## 宁德：原图与研究分类不同，不移动图线

用户提供的 B12 扫描图中，宁德城符号在宽 1800 像素预览约 (925,469)，对应 native 图幅约 (1593.1,807.7)。它在福宁/侯官虚线的南面、侯官片的斜线底纹内。虚线临海端约在预览 (938,430)，明显在宁德符号以北。因此「按此 B12 图幅落入侯官片」有直接的原图依据，并非本次像素配准把邻片城市挪了过去。本地核验裁图为 ignored `qa/south-B12-funing.jpg`，完整叠图为 `qa/south-B12-overlay.jpg`。

另一分类并非错误：秋谷裕幸（2022）《原始闽东区方言的 *yɑi 韵及其相关问题》，《中国语学》269号，第76–91页；**第77页表1（PDF第2页）**明确将宁德列入「闽东区—北片—福宁小片」，而文章第76页说明该谱系分类根据秋谷2010，第70页。[原论文与表1](https://www.jstage.jst.go.jp/article/chuugokugogaku/2022/269/2022_76/_pdf#page=2)。这是该论文所采用的分类，不能无条件覆盖用户所给历史图版。

福建省地方志《方言志》「二、福建方言的分区」的「福建境内汉语方言分区表」也将宁德和福安、周宁、寿宁等列入闽东方言北片；该网页无印刷页码，以章节和表名定位。[福建党史方志网原文](https://data.fjdsfzw.org.cn/upload/Annals/2011/%E6%96%B9%E8%A8%80%E5%BF%97/epub/ops/8.htm)。

建议界面并列显示：「地图集 B12：侯官片；另据秋谷裕幸（2022，第77页表1）：北片／福宁小片。分类体系存在差异，地图按所给原图描绘。」城市记录原有的福宁分类应注明来源体系；不要把它简单改成侯官，也不要为了匹配城市记录而移动 B12 图线。该差异不提供任何两地方言的实测互通率。
