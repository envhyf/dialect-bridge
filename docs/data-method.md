# 乡音桥：地图怎样成为可点击的区域

本版本只考虑汉语方言，采用用户所供历史图版的分类；不是最新人口调查，不保证与其他版本地图集的片名完全一致。

## 三种不同的空间对象

1. **总图色区**：A2 印刷颜色分割得到的概览。仅在地区详图未覆盖处回退使用，不把它伪装成片或小片。
2. **片、小片区域**：B1–B7、B9–B15 的14幅详图分别沿可辨认的原图语言界线人工概化描边。保留真实源像素，独立配准。尚未读取的地区缺失，不以省界、县界、泰森多边形或城市半径补齐。
3. **地点和居民点**：84 个地点用于语言分类和实验索引；其中15个进入已收录实验。66个四川盆地客家话居民点来自原图红三角，是不完整的符号转录，不扩大为面积。

## 修复了什么

旧版在形态学闭运算之后又用“非填色像素”强制清零，文字和河线因此重新变成孔洞。新版保留已修复的窄印刷中断，对其他明确填色、原图图框以及可分辨的大块空白继续保留约束。没有把所有无色区域涂满。

旧版40个 A2 控制点直接拟合二阶经纬度多项式，留一 RMSE 为21.94 km。新版在拟合的 Lambert 正形圆锥候选投影中做仿射配准，留一 RMSE 降到15.70 km。**这不证明原图使用了该投影**。原图投影、旧城市符号位置、扫描变形和现代城市中心差异仍会产生误差。

网页将所有经纬度图层送入同一显示投影。行政底图与历史描边存在偏差时，不能简单归结为网页的两个投影不一致；也不能强制吸附行政线来掩盖误差。行政边界始终独立绘制。

显示投影一致不代表大地坐标基准已获独立验证。[DataV官方格式说明](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/map-data-format-1)指出其地图组件主要使用GCJ-02；当前底图文件自身没有CRS声明，原始城市控制坐标也不是统一来源的实地测量。本版保留提供方底图坐标，未在缺少该文件明确基准说明时进行猜测性的二次转换。详见 `dist/data/basemap-metadata.json`。因此仍不宣称与现代行政边界严格无缝；可实证的修正是原图城市符号重定位、每图独立拟合、插图单独配准与按源色块修订轮廓。

## 详图配准与层级

地区脚本保留 sourceBoundary、sourceImageSize、源图 SHA-256、控制点和逐点留一误差。小弯曲经过人工概化；sourceBoundary 是扫描原图像素，不是屏幕坐标。sourceHoles 如存在则单独记录内环。多部件使用 sourceParts: [{outer, holes}]，包括首部外环；旧字段保留兼容。插图独立配准，但源像素始终相对整张原图，可以在网页本地加载同幅原图，与全部部件描线叠加对照。

详图数据文件：

- regions-north.geojson / regions-north-metadata.json：[B1–B5、B7说明](regions-north.md)
- regions-wu-gan.geojson / regions-wu-gan-metadata.json：[B9–B11说明](regions-wu-gan.md)
- regions-south.geojson / regions-south-metadata.json：[B6、B12–B15说明](regions-south.md)

assemble-regions.py 合并这些文件。只有小片而没有独立父片描边时，以已绘子片的几何并集生成父片，标记 derivedParent=true、partialCoverage=true；不填充未知空缺。不同图幅边缘及少量初描接缝仍需核校，不能据此判断具体村落。

每个区域记录 family / branch / cluster / subcluster / level / parentId。原版术语单独保留：例如 B2“北方官话”不直接套成现代整个北方官话的泛称；当现代城市分类与历史图层不一致时，研究匹配宁可为空。

区域数量、图幅清单和覆盖完整性以 regions.geojson 的 metadata 为准。片模式隐藏小片内界；小片模式叠加已知小片，其他位置仍显示父片或总图。

## 研究怎样关联区域

实测数据仅按具体实验的说者、听者及任务查询，不按距离插值。区域详情所列实验点同时满足：

- 该地点确实在研究数据中；
- 经纬度落在所选多边形内，且不落在内洞中；
- 方言大类、已知分支和片级分类相符。

这是检索关联，不表示实验覆盖整个区域。区域对象在数据模型中被明确禁止取得城市百分比，即使标识符误重名也不继承。没有匹配时写“未收录实测 / 未匹配样本”，不声称世界上没有相关研究。

海口原代表坐标使用偏西的新城区近似位置，与B12海南插图的海口旧城符号不对应。本轮以源图旧城控制点 [110.350,20.018] 校正代表点，并记录旧值与依据；没有为包住现代行政中心而扩大府城片。`scripts/update-representative-points.mjs` 可复现此修正。海口不属于当前已核验实验的15个点，修正不改变任何实验成绩。

`boundary-uncertainty.geojson` 单独记录已描区域的几何交叠及面积。网页用棕色斜纹显示，并在点击时列出当前层级的候选区域，不让绘制顺序决定归属。单凭交叠不能判断实际并用；原图明确记载的并用现象另见区域说明，也不能据此解释所有跨图冲突。父片模式隐藏同父小片之间的冲突纹理，已知父子包含不计为冲突。

同一方言类别的一份来源只有未分片色区、另一份已有相容细分时，交叠单独标为 `compatible-coarse-overlap`：保留两份原始几何与审计，点击优先显示具体片界，粗色区画在下方。候选片名不相容、两个已知分区彼此相交、或来源明确记载兼用时，不适用此规则，继续保留候选提示。此处理没有裁剪或移动任何边界。

不同图幅中同名、同大类、同分支的片与其小片，也按层级相容记录（`compatible-hierarchy-overlap`），例如 B15 粤台片与 B13 嘉应小片，不把父片覆盖子片渲染成大片冲突斜纹。不同分支或不同片名，以及两个小片之间的冲突仍保留。一个父片在同幅图中分为多个独立要素时，每个小片连接到实际交集最大的同类父片块；不改动任何原图轮廓。

片级视图里，同分类的直接描绘父片与自动并集父片同时覆盖该位置时，点击优先直接描绘的父片；并集父片仍保留为其他位置的局部回退，不生成两份同名分类的虚假歧义。

原实验的两种任务、方向、样本和局限见 [research.md](research.md)。默认面积颜色表示方言类别，蓝①/橙②标记说者与听者，片区淡亮表示层级包含。①→②与②→①分别读取原表，不按对称性推算；数字只归属于对应研究点。点击空白不会自动选择附近城市。

## 复现与验证

详见 README 的命令。A2 修复由 refine-overview.py 运行，旧 digitize.py 仅为旧版算法记录；不要用旧脚本覆盖新版文件。tests/test_segmentation.py 检查窄印刷缝隙修复和大空白保留。Node 测试覆盖多边形内洞、样本归属、层级显示与禁止区域继承成绩。发布检查要求区域非空、合法层级、闭合经纬度环、来源与父级可追溯，并禁止原图进入 dist。

公开仓库没有原扫描。atlas/manifest.json 只有图号和尺寸。本地原图仅用 object URL 读取，既不上传也不随部署发布。

## 显示线网 · 2026-11-17

`map-lines.geojson` 只用于绘制边线，按片与小片视图分别合并共线段，再连接连续线段；填色、点击判定与下载的方言区域仍使用原始多边形。行政底图共享线网独立显示为细虚线，外轮廓另绘；提供方少数无效环仅在计算行政外轮廓前调用 make_valid，原底图文件不改写。没有做无依据的投影转换、边界平滑或按行政区裁剪。

派生文件记录输入 SHA-256，公开版构建检查会拒绝过期线网。修改区域数据后运行 `python scripts/build-map-lines.py`。本轮改善的是重复边线、缩放精度与视觉层次，不代表原扫描图的地理误差已经消除。
