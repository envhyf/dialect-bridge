# 「乡音桥」地图数据说明

## 数据从哪里来

输入是用户提供的 `东方语言学《中国语言地图集》.zip` 中 A2《中国汉语方言图》与 B1–B15 地区图。当前数据采用这份历史地图的分类口径，不能当作最新人口调查或第二版地图集。

网页的方言色区来自 A2 扫描图的像素提取，并非把行政区多边形改名为方言区。行政区底图仅供定位，由主程序独立提供。

## 可复现的转换

运行 `python scripts/digitize.py` 可重新生成数据。脚本需要 Python、Pillow、NumPy、OpenCV；输入地图位于 `reference/`。

1. 原始 A2 图像为 3073 × 2292 像素，工作图缩放为宽 2000 像素。
2. 手工辨读图中的城市位置，记录 40 个像素位置与近似经纬度控制点。完整列表、拟合系数和逐点留一验证误差见 `dist/data/metadata.json`。
3. 使用二阶全局多项式，把图像坐标映射至经纬度。训练点距离误差 RMS 为 16.15 km；逐点留一验证 RMS 为 21.94 km，中位数为 17.29 km，最大值为 69.45 km。这些数字只描述配准误差，不是方言边界误差，也不是统计置信区间。
4. 将扫描图转换为 OpenCV CIELAB 色彩空间，按实际印刷色样匹配十个方言大类。去除图例、标题框、插图、纸色、海水及深色文字，辅以宽松的区域窗口，防止相近印刷颜色跨区域误识别。
5. 使用 5 像素闭运算、3 像素开运算处理细小文字与河线，再提取轮廓。面积不足 50 工作像素的碎片被丢弃，轮廓按 1.3 像素容差简化。输出遵循 GeoJSON 的经纬度顺序与外环逆时针方向。

当前输出为十个大类、89 个多边形部分。边界是自动提取的探索性近似结果，未逐县人工校正。混合语言纹理、文字、褪色、小岛和狭窄走廊会产生漏识别或误识别。不得用这些边界判断某一村镇一定属于何种方言。

## 代表点与分类

`cities.json` 包含 84 个代表点。每个点都有：

- `id`、`name`、`coordinates`：稳定标识、中文名称、近似定位经纬度；
- `family`：如吴语、闽语、官话；
- `branch`：官话分区、闽语分区；其余大类暂保留大类名；
- `cluster`：从地区图可辨读的更细分片。没有核实的层级为 `null`，不以大区名称冒充方言片；
- `source`：对应地区图编号；
- `variety`：实际被比较的地方语言名称；
- `note`：解释代表点范围与多语言情形；
- `sourcePixel`：仅对有 A2 控制点记录的城市提供图像坐标。不是全部城市都有原图像素坐标。

坐标是现代城市的近似定位，分类则是从历史地区图读取的代表性地方语言；它们不等同于原调查点坐标，不代表整座城市的居民语言。尤其南宁平话点不代表南宁城区粤语；台北、台南和新竹只比较所列闽南语或客家话。无数据区域表示未覆盖，而非“不能沟通”。

## 数字沟通模型的边界

这些地理文件没有互通率。地图提供分布与分类，不能直接推出百分比理解率。网页若根据分类层级给出分数，必须标为模型的接近度或探索指数，不能表述成“能听懂几成”的实测结果，也不能据此声称两地理解能力对称。

真实的互通程度需要具体听辨实验、词汇与句子测试，并受到接触经历、年龄、语速、语域和个体差异影响。相关实验方法可参考 Tang 与 van Heuven 的[互通性研究](https://www.sciencedirect.com/science/article/pii/S0024384108001678)；它不是本产品分值的校准数据。

## 客家话居民点图层

新增 `settlements.geojson` 独立点图层，人工辨读 A2 四川盆地范围内的 66 个清晰红三角符号，匹配图例“客家话居民点”。它们不是红色数字标签，也不是“西南官话和土话并用地区”的红星纹理。

每个点记录了 A2 原图的工作像素坐标、经相同多项式配准得到的经纬度和匿名编号。没有臆造聚落名，也没有把点扩大成连续分布区。截图核对文件为 `reference/settlements-sichuan.jpg`。这是局部选录，非全国完整居民点名录。居民点图层应作为独立三角符号显示，不能自动把附近城市的代表方言改为客家话。

## 输出文件

- `dist/data/dialects.geojson`：A2 像素转出的十类大区轮廓；
- `dist/data/cities.json` 与 `cities.geojson`：相同的 84 个代表点；
- `dist/data/metadata.json`：原图哈希、控制点、误差、算法与限制；
- `dist/data/settlements.geojson`：66 个原图客家话居民点的局部人工转录；
- `dist/atlas/manifest.json`：16 张引用地图的题名与图像路径；
- `reference/segmentation-preview.png`：色彩提取结果的目视检查图。

原图供用户私有网页中的来源核对使用，不把用户拥有的扫描件解释为可公开再发布的授权。
