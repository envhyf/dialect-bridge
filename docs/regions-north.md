# B2 / B3 / B7 方言片与小片：可复现的第一轮转录

本文件说明 `regions-north.geojson`，不是完整中国汉语方言分区。当前有 **34 个地理要素、27 个不同片/小片名称**：B2 14 个要素，B3 3 个要素，B7 17 个要素。同一片或小片的分离区域可能分开存储。

## 来源与轮廓

- B2《官话之二》：北京官话的京师、怀承、朝峰三片；原版“北方官话”保唐片的涞阜、定霸、天津、蓟遵、滦昌、抚龙小片；石济片的赵深、邢衡小片；沧惠片的黄乐、阳寿、章桓小片北块。
- B3《官话之三》：江淮官话洪巢片、泰如片、黄孝片。
- B7《晋语》：并州片、上党片；吕梁片的汾州小片及兴隰小片南北两块；邯新片的磁漳、获济小片；志延片西部主块及东部狭长片块；张呼片北部主体及中、南部独立片区；大包片主分布与晋中东部片块；五台片晋陕主体、河套和陕北南部片块。
- 保留所供地图版本的术语。B2 “北方官话”不是今天对所有北方官话的泛称，也未被悄悄替换为现代重新划分的分类。
- 人工读取原图颜色、纹理及片/小片界线，转录为多边形。**没有使用城市圆圈、行政区、多边形泰森分区或人为纬线切割替代原图。**文字、城市符号和浅色印刷破损没有作为洞扣掉。
- 这是概括轮廓的初描；小弯曲被简化，边界附近不能据此判定具体村庄的方言。含待补片块的要素以 `coverageComplete=false` 和 `evidenceNote` 逐项标明。

`sourceBoundary` 保存原始扫描像素坐标（原点左上，x 向右、y 向下）；首尾闭合。其单位不是工作预览像素。

## 配准方法与局限

每幅图分别读取可辨认的城市中心符号，以该城市经纬度为控制点。先把经纬度转换为 WGS84 Lambert 正形圆锥工作坐标（中央经线 105°，标准纬线 25° / 47°），再拟合工作预览像素到该投影的独立仿射变换，最终反变换得到经纬度 GeoJSON。没有借用全国图的变换系数，也没有把扫描页宣称为已经确定投影的标准 GIS 底图。

最初测试的二次多项式在控制点分布边缘有明显留一外推不稳定性，最终发布使用投影坐标中的仿射拟合。控制点逐项位置、留一误差、工作 CRS、拟合系数及原图 SHA-256 均在 `regions-north-metadata.json`，可复核源像素与地理坐标的转换。

这里的 RMSE 是**控制点留一预测误差**，不表示方言边界拥有同等精度，也不是人工描线误差。历史城市符号、现代中心经纬度、扫描形变及原图投影未确认均限制定位精度。此版只适合片/小片层级的探索性展示；应继续用原图经纬网和更多分散控制点改进配准。

## 研究证据

这批要素只提供地域及分类，不承载两片之间的实测互通比例。区域记录中的研究状态只表示本数据文件没有给该片块绑定覆盖全区域的测量。网页应另从真实研究的测试地点和测试方言对匹配研究，不能把某两个城市的实验推广为整个片或小片实测结果。

没有匹配实测的点击结果应显示“未匹配到该方言对的实测研究”。这不等于宣称研究不存在。分类接近度或模型估计必须与实测分开。

## 复现与检查

在项目目录运行：

```text
python scripts/regions_north.py
```

依赖：Pillow、NumPy、Shapely、pyproj。私有原图读取位置为相邻目录 `dialect-atlas/reference/B2.JPG`、`B3.JPG` 和 `B7.JPG`，原图及带原图的 QA 预览均不属于公开数据。

脚本生成两个公开 JSON 文件，及仅用于本地检查的 `qa/north-B2-outlines.jpg` / `qa/north-B3-outlines.jpg` / `qa/north-B7-outlines.jpg`。已目视检查这三幅叠线图。自动检查结果：34 个非空有效 Polygon；同一图幅的输出要素之间无面积大于 0.000001 平方度的重叠。相邻原图边界尽量复用顶点；尚未描绘的片区保持缺失。
