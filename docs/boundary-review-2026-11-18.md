# 边界与标签复核 · 2026-11-18

本轮针对湖南放大截图、西北秦陇片孤块及成渝片标签复核，没有把全部图幅重新测绘，也没有识别出地图集原始投影。

- **成渝片标签**：此前把 `humanLabel` 的“成都、重庆”放在整个片的质心，又绘制了城市圆点，容易误认地点。现在区域只标正式片／小片名，不画城市点；真实城市继续使用城市坐标。区域标签使用最大多边形内的可容纳位置，避开孔洞，不能把这个位置理解为居民点。
- **名称**：片块序号属于内部要素编号，不是方言分类。地图使用 `subcluster`、`cluster` 等正式字段显示名称，独立片块仍保留各自数据ID；原始来源记录不抹去。
- **湖南 B11**：复读长益片、娄邵片、吉溆片的纹理与虚线界，纠正早期以近邻河道近似片界的折线。原图1800×1336工作像素中提取黄色外缘，7像素闭运算修复印刷文字与细河线，保留面积至少120工作像素的内孔，轮廓以0.8工作像素概化。三片使用同一组内部边线；洞绥片使用同一个实际内嵌环，避免独立描线产生缝隙。西侧小条状的娄邵片依原图竖纹明确保留。脚本中的种子只是对已经切分的印刷色面核对纹理归类，不从城市点生成区域。
- **西北 B4**：正宁的秦陇片三角孤块有原图虚线和短划纹依据，保留。另一个同心南界的细三角是人工裁切直线落进陇中色面所致：将该裁切线移到已扣除的黄色区，由真实色面外缘决定边界，移除错误 `b4-qinlong-7`。其他秦陇片块与关中片未改。
- **选中样式**：原CSS固定绿色覆盖了方向颜色；现在保留蓝／橙方向，并收细白色衬线，真实孔洞不删除。

当前191个来源描边要素、10个局部合并父片。B11配准留一RMSE仍为5.831公里，B4为7.89公里；它们是控制点配准诊断，不是描线精度。跨图幅的其他白缝和交叠仍存在，继续明确标识；不靠行政裁切或随意填色假装完成校准。

复现：`python scripts/regions_wu_gan.py`、`python scripts/regions_north.py`、`python scripts/assemble-regions.py`、`python scripts/build-map-lines.py`。前两项需要私有原图。无需原图的回归检查：`python tests/test_boundary_revision.py`。原图叠线检查图片仅存本地忽略目录，不公开发布。
